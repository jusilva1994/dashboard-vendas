# 📊 Dashboard Dinâmico de Vendas e Assinaturas

 Este projeto apresenta um Dashboard de Vendas e Assinaturas construído a partir da base de dados de vendas (base-de-dados.xlsx / dashboard-finalizado.xlsx). O objetivo principal do painel é fornecer métricas visuais estratégicas, acompanhamento financeiro em tempo real e análise de comportamento dos assinantes para tomada de decisão rápida e assertiva.

# ⚡ Atualização Dinâmica dos Dados

Um dos principais destaques deste dashboard é a sua natureza dinâmica:

Conexão Direta com a Base de Dados: Todos os indicadores, gráficos e cartões de KPI estão vinculados diretamente a tabelas dinâmicas.

Filtros e Segmentações Interativas: Ao utilizar os filtros visuais (como período, tipo de renovação ou modalidades de assinatura), todos os gráficos e métricas recalculam e atualizam instantaneamente.

Escalabilidade: Novas entradas registradas na base de dados original são refletidas automaticamente no painel com uma simples atualização de dados.

# 📈 Informações de Vendas Exibidas no Dashboard

O painel está estruturado em 4 blocos principais de análise:

## 1. Indicadores Chave de Desempenho (KPIs Principais)

Receita Total (R$): Soma acumulada de todo o faturamento gerado com assinaturas e adicionais.

Volume Total de Assinantes: Quantidade de clientes ativos/vendas registradas na base.

Ticket Médio (R$): Valor médio gasto por cliente por assinatura.

Taxa de Renovação Automática (%): Proporção de clientes com renovação automática ativa (Yes vs. No), métrica essencial para previsão de receita recorrente (MRR/ARR).

## 2. Evolução Temporal das Vendas

Faturamento Mensal: Gráfico temporal exibindo a oscilação da receita mês a mês (destaque para o pico de vendas em outubro/2024 acumulando R$ 610,00).

Análise de Sazonalidade: Permite identificar meses com maior ou menor entrada de novas assinaturas.

## 3. Mix de Planos e Modalidades de Assinatura

Receita por Tipo de Assinatura: Comparativo de desempenho financeiro entre planos Mensais, Trimestrais e Anuais (com destaque para os planos mensais liderando a representatividade da receita).

Distribuição do Plano Ultimate: Análise detalhada do volume de vendas por modalidade do plano principal.

## 4. Cross-selling e Descontos

Adesão a Passes Adicionais: Acompanhamento das vendas cruzadas de complementos como EA Play Season Pass e Minecraft Season Pass.

Impacto de Cupons: Distribuição e frequência das faixas de desconto (R$ 3 a R$ 20) aplicadas sobre o valor total.

# 🛠️ Tecnologias Utilizadas

Microsoft Excel / Google Sheets: Tabelas Dinâmicas, Formatação Condicional e Segmentação de Dados (Slicers).

Markdown: Documentação do repositório.

# 🚀 Como Visualizar

Faça o download do arquivo dashboard-finalizado.xlsx.

Abra no Microsoft Excel ou Google Sheets.

Utilize os botões de segmentação no topo da tela para interagir dinamicamente com os relatórios e gráficos!
